# Security

Report a vulnerability in this library or in the AY Inbox API to team@ayinbox.com. Please do not open a public issue for it.

Include what you found, how to reproduce it and the version you used. We will confirm we received it and tell you what we plan to do.

Never include a real API key, webhook secret or customer data in a report. If a key was exposed, revoke it in the AY Inbox dashboard first.
